# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-22

### Added
- Initial release
- Multi-group Facebook posting automation
- Campaign management interface
- Text and image posting support
- Real-time campaign monitoring
- Error tracking and group failure monitoring
- Developer logs export functionality
- Native host logging support for Windows
- Declarative Net Request API integration
- Chrome Manifest V3 compatibility

### Features
- Create and schedule posting campaigns
- Select multiple Facebook groups for simultaneous posting
- Upload images with post content
- Monitor campaign progress in real-time
- Export logs for debugging and analytics
- Optional native logging via PowerShell setup

### Technical
- Service Worker-based background processing
- Chrome storage for persistent data
- Alarm-based campaign step processing
- Native messaging for logging (optional)
- GraphQL integration for Facebook group fetching
